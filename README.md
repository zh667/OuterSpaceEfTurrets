# 工业防御塔 · EfTurrets

《Outer Space / 秩序：新曙光》（Steam 3080070）的防御塔模组：把《明日方舟：终末地》的 19 座防御塔做进游戏，接入游戏自己的建造菜单、科技树和炮塔逻辑。非官方模组，与两款游戏的开发商无关。GPL-3.0 开源（只限本仓库的代码和脚本）。

## 内容
| 级别 | 科技 | 防御塔 |
|---|---|---|
| 1 | 工业炮塔基础 | 铳械塔、榴弹塔、激流塔（水柱击退） |
| 2 | 工业炮塔强化 | 扩装铳械塔、液氮塔（冰面减速）、“酸洗”（落点一摊酸液，腐蚀后受伤增加）、医疗塔（给人回血、给建筑修耐久） |
| 2 | 电涌技术 | 电涌塔（电弧在敌人之间弹跳） |
| 3 | 工业炮塔自动化 | “暴雨”铳械塔、高爆榴弹塔、哨戒塔、AF1“熔甲者”（喷火，地面持续燃烧） |
| 3 | 化学阵地 | “毒沼”（落点一片毒液，持续伤害并减速）、全向声波塔（周围一圈眩晕） |
| 3 | 射线技术 | 射线塔 |
| 4 | 工业重火力 | 重锤迫击炮（3×3，有最小射程）、序章炮塔（4×4） |
| 4 | 高能技术 | 高能射线塔、甲二型“电荷”（留下电球持续放电） |

- 每座塔用原游戏模型预渲染 24 个方向，转向和开火朝向都按游戏的炮塔逻辑走，炮口位置从画面里读取。液氮、酸洗、毒沼的发射器另渲染 7 档仰角：瞄准时按目标距离抬到弹道的发射角再开火，空闲时放平。
- 子弹、爆炸、粒子特效全部用游戏自带的素材（`Eff_Defense`、`Eff_Bullets`、`Eff_Groung` 和特效图集），跟原版炮塔一个画风；毒气、水雾、电火花、冲击环用游戏特效里的烟雾、光晕、火花、光环贴图，由模组控制运动和颜色。
- 酸洗、毒沼落点留下一摊酸液/毒液，液氮结成冰面，熔甲者和电荷留下焦痕；地面贴图由 `tools/assets/make_ground.py` 用游戏自己的地形纹理生成，焦痕直接用游戏的 `groundburn.png`，昼夜光照和地面一致。
- 数值按游戏原版同级、同类炮塔对齐：每秒伤害、射程、血量、耗电最多高三成左右；射程不低于原版最短的 15 格（医疗塔 10 格除外），抛射类 22～26 格。
- 科技节点挂在游戏原有同级防御科技旁边，位置由 `tools/tech_layout.py` 对整棵科技树搜索得出，不压原有的卡片和连线。

## 素材
仓库里**没有**任何模型或贴图。塔的图片要在本地用你自己拥有的原游戏模型生成：
1. `python tools/assets/render_all.py [force] [ids]`：用 Blender 5.1 渲染 24 个方向（模型路径在脚本开头的 `SRC`）。
2. `python tools/assets/make_assets.py`：拼成游戏的精灵文件和图标，输出到 `local/gen`（不进 git）。
3. `python tools/assets/make_ground.py`：生成地面效果贴图（读游戏安装目录里的地形图）。

原游戏模型和名称的权利归各自所有者。

## 构建与安装
Windows：`python tools/build.py`（加 `install` 复制到 `<游戏>/mods/EfTurrets`，只替换 `Manifest` 和 `v_common`，旧安装先备份到 `dist/replaced-*`）。目标 net472，直接引用游戏 `Outer Space_Data/Managed` 的 DLL。装好后在游戏的模组菜单里启用一次。

## 测试
`python tools/run_isolated.py --save <星球上的存档> --exact-save`：在游戏的隔离副本里运行 `src/SelfTest.cs`，原版游戏和玩家存档只读。自测会检查表格行和科技、把 19 座塔放到地图上、每座塔各打一场（特殊塔按自己造成的命中、击退、减速、眩晕判定）、医疗塔回血和修理，并截图。`--tests techtree` 只打开科技树、对每个新节点截图；`ground` 铺出所有地面效果；`plan` 检查放置预览的方向；`power` 检查不通电的塔不开火；`dps` 实测每座塔和原版同类炮塔的每秒伤害；`fxpreview` 拍特殊塔的近景特效序列。

需要游戏 0.9.0020 或更新（模组逻辑跑在游戏的模拟线程上，特效转回主线程绘制）。
